#  WINDOWS TROUBLESHOOTING NOTES:
# - Do NOT install `xformers`. PyTorch 2.5.1 has native SDPA (Flash Attention) built-in. Compiling xformers on Windows is unnecessary and prone to failure.
# - If your script crashes with `AttributeError: module 'torch' has no attribute 'int1'`, it means a package automatically pulled in `torchao` which breaks PyTorch 2.5. Fix it by running:
#   pip uninstall -y torchao
